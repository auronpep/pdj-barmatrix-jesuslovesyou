# Final Sprint Adaptive Sheet Prompt v2

Create one daily Final Sprint web sheet.

## Inputs

- Final_Sprint_Snapshot
- user weakness profile
- bank-wide high-yield keys
- hand-curated priorities
- available drills / examples / mnemonics
- previous sprint sheet completions

## Output

One sheet with:

- title
- theme
- primary goal
- Must Do
- Should Do
- Extra
- mixed targets
- completion rule

## Rules

1. Sheet may mix subjects and colors.
2. Do not force one subject per day.
3. Overloaded is acceptable if priority tiers are clear.
4. Web-first only.
