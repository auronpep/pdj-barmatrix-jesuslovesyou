## Trap Key module

Show when:

- selected wrong answer maps to a Trap Key;
- unseen adjacent Trap Key is triggered;
- same repair cell contains an unseen high-priority Trap Key;
- Final Sprint selected the Trap Key.

## Annotated Solve Board

The Annotated Solve Board should render validated scaffold data:

- call lock;
- stem annotations;
- solve steps;
- answer decode;
- color diagnostic strip;
- bank-it line;
- repair prompt.

It should not be generated from free prose alone.
